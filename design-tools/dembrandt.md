# Dembrandt ｜ 网站设计资产与 Token 提取

## 仓库
- **dembrandt/dembrandt**

## 功能描述
从网页中提取 Logo、颜色、字体、间距、边框、阴影与组件规律，整理为可复用的设计资产和 Design Tokens。

### 核心特性
- 提取网站视觉资产
- Design Tokens
- 可用于建立 DESIGN.md / Tailwind theme
- 适合逆向学习品牌视觉系统

## 安装
```bash
npm install -g dembrandt
dembrandt install-browser
```
