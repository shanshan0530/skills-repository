# Impeccable ｜ AI 设计质量工具

## 仓库
- ** pbakaus/impeccable**
- GitHub 内置 Skill（Copilot Pro / Enterprise）

## 功能描述
给 AI 一套设计规则，像给初级开发者一本风格指南。Impeccable 成为生成顶部的质量层，确保 AI 生成的代码符合设计规范。

### 核心特性
- 40k+ GitHub stars（ launch 时即获得）
- 现已成为 GitHub Copilot 内置 Skill
- 23 个命令：`audit` / `polish` / `distill` / `critique` / `adapt` / `animate` / `bolder` / `clarify` / `colorize` / `delight` / `harden` / `layout` / `onboard` / `optimize` / `overdrive` / `quieter` / `shape` / `typeset` 等
- 独立 CLI：`npx impeccable`（无需 AI harness 即可检测反模式）
- 自动生成 `PRODUCT.md` + `DESIGN.md`
- 设计钩子（design hooks）尊重每个应用，monorepo 安全

### 适合场景
- 提升 AI 生成代码的设计质量
- 设计审计（audit）
- 项目初始化设计系统
- 作为 GitHub Copilot 的内置设计质量层

## 安装
```bash
# 作为独立 skill
npx skills add pbakaus/impeccable

# 或使用 CLI（无需 AI harness）
npx impeccable

# GitHub Copilot 用户可直接使用内置 skill
```
