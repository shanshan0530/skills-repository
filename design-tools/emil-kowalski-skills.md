# Emil Kowalski Skills ｜ 动效与界面品味技能集

## 仓库
- **emilkowalski/skills**

## 功能描述
一套给设计师和工程师用的 Agent Skills，重点解决 AI 做 UI 时常见的动效审美、节奏、缓动、交互细节和界面质感问题。

### 主要 Skills
- `emil-design-eng`：综合 UI polish / component / animation 设计判断
- `animate`：从零实现动画，决定是否该动、用什么曲线、时长和属性
- `review-animations`：严格审查已有动画
- `improve-animations`：扫描整个代码库并给出优先级优化方案
- `find-animation-opportunities`：找出本该有动效但缺失的位置
- `animation-vocabulary`：把模糊的动效描述转成更精准的专业术语
- `apple-design`：把 Apple 的界面与流畅动效原则整理成可执行规则
- `prototype`：做多个差异化 UI / 动效方案进行对比
