# Hue ｜ 自动生成设计语言 Skill

## 仓库
- **dominikmartn/hue**

## 功能描述
一个用于生成设计语言 Skill 的 meta-skill，可根据截图、品牌或描述，把字体、颜色、间距、组件和动效规则整理成可复用约束。

### 核心特性
- 从视觉参考生成设计语言
- 适配 Claude Code / Codex
- 让不同会话保持更统一的视觉输出
