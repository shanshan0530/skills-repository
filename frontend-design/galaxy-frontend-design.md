## 功能描述
用于生成具有明确视觉方向、可直接落地的高质量前端界面，重点避免常见的 AI 模板感和千篇一律的组件化审美。

### 核心特性
- 强调先确定清晰的设计方向，再开始编码
- 支持极简、编辑感、复古未来、工业、Art Deco、自然、有机、实验性等多种视觉路线
- 要求界面具备明确记忆点，而不是只做“干净好看”
- 强调排版、空间构图、动效、背景纹理与细节氛围
- 明确反对 Inter / Roboto / Arial 等默认感强的字体与套路化布局
- 鼓励打破常规网格、使用非对称、重叠、斜向流动与更有性格的视觉结构
- 适用于 HTML / CSS / JS、React、Vue 等前端实现

### 适合场景
- 网站与 Landing Page
- Dashboard / Web App
- React / Vue 组件
- 海报式网页与视觉型页面
- 已有 UI 的视觉重构与去 AI 模板化
