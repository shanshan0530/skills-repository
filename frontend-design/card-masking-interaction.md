# Card Masking Interaction ｜ 敏感信息脱敏显示与交互

## 来源

- 分享链接：小红书设计笔记

## 功能描述
针对卡号、身份证号等敏感信息的脱敏显示与交互方案。默认隐藏敏感部分，仅在用户主动点击时查看明文，同时提供一键复制与状态反馈，让用户在安全与便捷之间取得平衡。

### 核心特性
- **默认脱敏显示**：敏感信息默认隐藏关键片段（如 `4485 **** **** 7516`），避免直接暴露
- **点击查看明文**：通过眼睛图标触发，仅在用户需要时显示完整信息
- **一键复制**：查看状态下支持快速复制，减少手动选择与长按操作
- **状态反馈**：复制完成、查看切换均有明确视觉反馈
- **减少操作步骤**：核心理念是让用户少想一步、少操作一步

### 设计原则
- 好的交互往往不炫技，而是减少用户的认知负担与操作成本
- 安全与便捷不是对立面，可以通过恰当的交互设计兼顾

## 适合场景
- 支付页面中的卡号、CVV 展示
- 设置页面中的 API Key、Token 展示
- 个人中心中的身份证、手机号展示
- 任何涉及敏感信息但需要用户参考或复制的场景
