# Motion Web ｜ 动效优先的创意网页工程体系

## 仓库
- ** feitangyuan/motion-web**

## 功能描述
一个面向 Agent 与前端开发者的动效与创意网页工程体系。坚持"动效即材质"（Motion is the Material），拒绝浮于表面的装饰性动画，通过真实的物理模拟、严苛的排版与设计系统约束，交付兼具审美手感与生产级代码质量的创意交互页面。

### 核心特性
- 7 大完整、可运行、可验证的交互案例
- 真实物理模拟（弹簧阻尼、Verlet 积分、流体力学）
- 技术栈：vanilla Three.js / Canvas 2D / WebGL / CSS
- Claude Code / Codex / Antigravity Skill
- Playwright headless 自动化验证
- MIT  licensed

### 案例列表
1. **string-clock**：软体弹性绳索时钟
2. **ink-crowd**：原生 WebGL2 墨线群集
3. **press-stack**：粘性叠层唱片封面
4. **wheel-rail**：滚轮驱动视差轨道
5. **toy-flipbook**：硬切翻页与阶梯抖动
6. **char-curtain**：独立 Verlet 绳排门帘
7. **lyre-crows**：因果生态文字猎鸟

### 设计原则
- 动效即材质，不是装饰
- 真实物理模拟
- 严苛排版与设计系统约束
- 生产级代码质量
