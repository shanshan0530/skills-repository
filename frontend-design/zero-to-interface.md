# Zero to Interface ｜ 从零到界面的设计 Skill

## 仓库
- **Wanyi4424/zero-to-interface**
- GitHub: https://github.com/Wanyi4424/zero-to-interface

## 功能描述
从视觉灵感、参考素材和设计方向出发，逐步整理并推进到可落地的界面设计。仓库本身包含 `agents`、`assets`、`references`、`README.md` 与 `SKILL.md` 等内容，明显是围绕“从零到界面”的完整设计流程组织。

### 核心特性
- 从模糊视觉方向推进到具体界面
- 结合参考素材、视觉语言与界面结构
- 提供 Skill 文档与辅助资源目录
- 适合前端 UI / 产品界面设计流程

### 适合场景
- 从空白开始搭建产品界面
- 依据视觉参考做 UI 延展
- 需要把设计方向逐步落成可实现界面
