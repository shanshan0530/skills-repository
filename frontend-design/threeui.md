# ThreeUI ｜ 3D 粒子/流体/鼠标跟随动效组件库

## 仓库
- ** MengTo/threeui**
- 官网：[threeui.com](https://threeui.com)

## 功能描述
开源 React + Three.js 组件库，快速制作 3D 粒子、流体、鼠标跟随等网页动效。上线一周 Star 破 4000。

### 核心特性
- 160+ 免费组件（Community 版）
- 50+ Pro 组件（付费）
- 程序化 3D hero sections、icons、motion designs
- 支持复制提示词或源码给 AI agent
- 可自定义主题、灯光、运动、布局
- 包含 MCP 和 skills（Pro 版）

### 组件类别
- 背景（Backgrounds）
- 按钮（Buttons）
- 文字动画（Text animations）
- 落地页样式（Landing page sections）
- 3D 粒子效果
- 流体模拟
- 鼠标跟随效果

### 使用方式
1. 复制组件提示词或源码
2. 粘贴到 Codex / Claude Code 等 AI agent
3. 自定义主题、灯光、运动、布局
