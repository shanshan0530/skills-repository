# ThreeUI ｜ React + Three.js 3D UI 组件库

## 仓库
- **MengTo/threeui**

## 功能描述
开源 React 3D / WebGL 组件与交互模板库，适合给网页加入 3D Hero、背景、按钮、图标和空间感动效，而不用从零手搓 Three.js。

### 核心特性
- React + Three.js / WebGL
- 可复制粘贴的 3D UI 组件
- 交互式模板与参数调节
