# Motion Sites ｜ 高质量网站提示词素材库

## 仓库
- ** nomaan5541/motionsites-prompt-collection**
- 官网：[motionsites.ai](https://motionsites.ai)

## 功能描述
177+ AI 网页设计提示词模板，专为 React + Tailwind CSS + Framer Motion 优化，复制即可使用。

### 核心特性
- 177+ 提示词模板
- 覆盖：SaaS、Agency、Portfolio、Landing Page 等
- 每个 prompt 包含：metadata（category / type / license）+ 完整 prompt_text
- 支持 React + Tailwind CSS + Framer Motion
- 开源社区维护

### 使用方式
1. 浏览 prompts 目录
2. 复制 `## Prompt` 区块
3. 粘贴到 AI 工具生成网页
