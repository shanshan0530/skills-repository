# Morphicons ｜ SVG 图标变形动画库

## 仓库 / 官网
- **guillermolg00/morphicons**
- https://www.morphicons.com/

## 功能描述
让两个 SVG stroke 图标自动计算形状对应关系并生成平滑 morph 动画，例如菜单变关闭、播放变暂停，不需要手动画逐帧。

### 核心特性
- 支持 Lucide、Tabler、Heroicons、Iconoir 等
- React / Vue / Svelte / React Native / Astro
- spring physics
- 零运行时依赖
- Core gzip 约 6.5 KB
- MIT License

## 安装
```bash
npm install morphicons
```
