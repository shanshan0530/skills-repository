# Awesome Design MD ｜ 大厂 UI 设计规范库

## 仓库
- ** VoltAgent/awesome-claude-design**（原 awesome-design-md）

## 功能描述
整理了几十家大厂的 UI 设计规范文档，把复杂的设计系统浓缩成纯文本 Markdown 文件，直接给 AI 就能生成对应的前端代码。

### 核心特性
- 50+ 真实网站的 DESIGN.md 文件（Vercel / Linear / Stripe / Supabase / Notion / Apple / Spotify 等）
- 每个文件包含：色彩配置、排版规则、组件样式、阴影系统、响应式行为
- 附带 `preview.html` / `preview-dark.html` 即时预览
- 轻量无依赖：纯文本，版本控制友好
- 格式专为 LLM 上下文窗口和逻辑推理优化

### 使用方式
1. 挑选并复制想模仿的 `DESIGN.md` 到项目根目录
2. 直接对 AI agent 下达指令
