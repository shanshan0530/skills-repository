# BoardUI ｜ Agent / Dashboard React 设计系统

## 仓库 / 官网
- **BoardUI/boardui**
- https://www.boardui.com/

## 功能描述
专门面向 dashboard、数据密集界面和 agentic interface 的 React 设计系统，提供组件、图表、模板与 AI Chat 示例。

### 核心特性
- React + Tailwind CSS
- 数据表格、图表、Stat 卡片、Dashboard 模板
- AI / Agent 界面组件
- 支持 MCP，让 Claude Code / Cursor / Codex 直接浏览和安装组件
- 免费组件源码公开，MIT 协议；Pro 内容另有商业授权

## MCP
```bash
claude mcp add boardui -- npx -y boardui@latest mcp
```
