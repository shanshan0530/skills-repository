# Design Extract ｜ 从网站反向提取设计系统

## 仓库
- **Manavarya09/design-extract**

## 功能描述
从真实网站提取配色、字体、间距、动效和视觉语言，并整理为可复用的设计系统资料。

### 核心特性
- 从 URL 提取视觉规则
- 可整理 Design Tokens
- 适合逆向学习网站审美与样式结构

## 安装
```bash
npx skills add Manavarya09/design-extract
```
