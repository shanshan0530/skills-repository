# UI Layouts ｜ 复制即用的 React/Tailwind 组件与区块库

## 官网
- [ui-layouts.com](https://ui-layouts.com/)

## 功能描述
免费 + Pro 的前端 UI 资源站，提供大量可直接复制粘贴的 React/Tailwind 组件和 100+ 现成页面区块，快速拼出现代化界面。

### 核心特性
- 免费组件：手风琴、按钮、标签输入、文件上传、日期时间选择器、图片揭示、鼠标轨迹特效、液态玻璃效果等
- 现成区块（Blocks）：Hero / Feature / About / Team / Stats / Testimonial 等分类，100+ production-ready blocks（Pro）
- 视觉风格突出：主打 3D 效果、动画与极简设计
- 与 shadcn 生态兼容，支持 shadcn registry 集成
- 提供 MCP 服务、Discord 社区与 cursify 等子工具站点
- 社区口碑集中在 r/tailwindcss、r/shadcn、r/react

### 适合场景
- 快速搭落地页/官网，不想从零写 Hero、Feature 区块
- 给 shadcn 项目加炫酷交互组件
- 找 3D / 动效灵感

## 使用
打开官网 → 选组件或区块 → 复制代码进项目。Pro 为付费版，免费组件已覆盖日常需求。
