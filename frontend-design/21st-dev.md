## 功能描述
社区驱动的 React UI 组件库平台，提供高质量、可复用的组件和模板。

### 核心特性
- 12,000+ crafted React components, templates, shadcn themes
- 2,000+ Marketing blocks（animated heroes、shaders、liquid & metal、backgrounds、gradients）
- 2,100+ UI components（buttons、AI chats、cards & grids、galleries & 3D、navigation、sign ins & widgets）
- 支持复制 AI-ready prompt 到 Cursor / Claude Code / v0 / Lovable
- 实时预览
- 免费使用（有限制）

### 使用方式
1. 浏览组件库
2. 预览效果
3. 复制 AI-ready prompt
4. 粘贴到 AI agent 生成代码
