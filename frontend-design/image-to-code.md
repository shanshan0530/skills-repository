# Image to Code ｜ 截图转前端代码

## 仓库
- ** OneWave-AI/claude-skills** → `screenshot-to-code`
- 备选：** openai/image-to-code**（OpenAI 官方 Skill）

## 功能描述
把 UI 截图直接生成可用的前端代码，快速复刻页面。

### 核心特性
- 输入：UI 截图（网站 / 移动端 / 设计稿）
- 输出：响应式 React / Vue / HTML+CSS 实现
- 分析布局结构、组件、视觉样式
- 提供完整、可运行的实现代码

### 适合场景
- 截图直接生成前端代码，快速复刻页面
- 将设计稿转换为生产级代码
- 需要高视觉保真度的还原

## 安装
```bash
npx skills add --skill screenshot-to-code
```
