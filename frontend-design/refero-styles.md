# Refero Styles ｜ 设计系统库

## 仓库
- ** fidgetcoding/refero-design-mcp**（MCP server）
- ** referodesign/refero_skill**（Research-first design skill）
- 官网：[styles.refero.design](https://styles.refero.design)

## 功能描述
约 200 套 curated 设计系统的自然语言搜索库，每套包含完整的 DESIGN.md 文件。

### 核心特性
- 200+ curated sites（Apple、Linear、Cursor、GitHub、Vercel 等）
- 自然语言搜索（vibe search）
- 返回结构化 DESIGN.md（颜色、排版、间距、动效、组件模式）
- 兼容 `/stitch-design-taste` 和 `/design-taste-frontend` skills
- 支持按品牌名、mood（minimal/editorial/playful/high contrast）、颜色、字体、URL 搜索

### MCP Tools
- `refero_search`：自然语言搜索
- `refero_get`：获取完整设计系统（支持 uuid / hostname / site name）
- `refero_similar`：相似风格推荐
