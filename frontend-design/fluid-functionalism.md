# Fluid Functionalism ｜ 功能性动效组件库

## 仓库 / 官网
- **mickadesign/fluid-functionalism**
- https://www.fluidfunctionalism.com/

## 功能描述
强调“动效是信息而不是装饰”的开源 UI 组件库，通过 spring physics、proximity hover 和状态连续性，让界面动效更自然、更有功能意义。

### 核心特性
- 基于 shadcn/ui
- Radix UI / Base UI primitives
- Spring physics 取代死板 duration
- Proximity hover、滑动指示器、Animated Select、Thinking Steps 等
- Next.js 15 + React 19 + Tailwind CSS v4 + Framer Motion
- MIT License

## 安装
```bash
npx shadcn@latest registry add @fluid
npx shadcn@latest add @fluid/button
```
