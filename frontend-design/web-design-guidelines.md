# Web Design Guidelines ｜ 网页设计规范审查

## 仓库
- ** vercel-labs/agent-skills** → `skills/web-design-guidelines`

## 功能描述
Review UI code for Web Interface Guidelines compliance，由 Vercel 工程团队出品。自动检查网页细节问题，覆盖布局、排版、颜色、动效和无障碍。

### 核心特性
- 审查现有前端代码是否符合 Vercel Web Interface Guidelines
- 覆盖：Layout / Typography / Color / Motion / Accessibility
- 每次审查自动从上游 URL 获取最新规则（可离线固化）
- 输出简洁的 `file:line` 格式报告

### 适合场景
- 前端开发者在合并/发布前做一次客观的 a11y + UX 审查
- 检查网站是否符合最佳实践
- 设计审计（audit design）

## 安装
```bash
npx skills add --skill web-design-guidelines
```
