# beUI ｜ React 动效组件库

## 仓库 / 官网
- **starc007/ui-components**
- https://beui.dev/

## 功能描述
面向 React / Next.js 的动画组件库，组件通过 shadcn registry 以源码形式安装，适合快速给 Vibe Coding 页面补上更自然的交互动效。

### 核心特性
- Motion / Framer Motion 动效组件
- Dynamic Island、Animated Toast、Bottom Sheet、Drawer、Dock、Morph Modal 等
- 组件直接复制进项目，不依赖黑盒运行时
- 提供专门给 AI Agent 读取的 registry / llms.txt
- MIT 协议

## Skill 安装
```bash
npx skills add starc007/ui-components --skill beui -g -y
```

## 组件安装示例
```bash
npx shadcn@latest add @beui/animated-toast-stack
```
