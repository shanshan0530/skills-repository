# React Bits ｜ 炫酷交互动效组件库

## 仓库
- ** DavidHDev/react-bits**
- 官网：[reactbits.dev](https://reactbits.dev)

## 功能描述
开源免费的 React 动画交互组件库，140+ 炫酷组件，即选即用。

### 核心特性
- 165+ 组件（text animations、UI elements、backgrounds）
- 4 种变体：JS-CSS、JS-TW、TS-CSS、TS-TW
- 极简依赖、tree-shakeable
- 复制粘贴即用
- 创意工具：
  - **Background Studio**：动态背景探索与导出
  - **Shape Magic**：内圆角形状生成（SVG / React / clip-path）
  - **Texture Lab**：20+ 效果（noise、dithering、ASCII）
- 支持 shadcn 和 jsrepo CLI 安装

### 组件类别
- 💬 Text Animations
- 🌀 Animations
- 🧩 Components
- 🖼️ Backgrounds
