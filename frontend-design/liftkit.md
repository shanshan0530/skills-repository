# LiftKit ｜ 组件与视觉比例规范

## 仓库
- **Chainlift/liftkit**

## 功能描述
一套强调视觉比例、间距、颜色与光学平衡的 UI framework，可作为 AI 生成界面时的组件和视觉规范参考。

### 核心特性
- spacing / scaling / color 规则
- optical balance
- 组件化 UI 规范
