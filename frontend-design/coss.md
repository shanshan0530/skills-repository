# Coss ｜ 现代组件系统

## 仓库
- **cosscom/coss**

## 功能描述
面向 React 的现代组件体系，提供统一的组件、间距和视觉层级规范，可作为 Agent 生成界面时的组件基础。

### 核心特性
- React 组件体系
- Base UI / Tailwind 风格工作流
- 适合 Button、Dialog、Select、Form、Menu、Tabs 等基础组件统一
