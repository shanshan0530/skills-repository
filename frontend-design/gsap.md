## 功能描述
GreenSock 官方出品的 AI Skill，教 AI coding agents 正确使用 GSAP（GreenSock Animation Platform）。

### 核心特性
- 15.1k+ GitHub stars
- MIT  licensed
- 涵盖：核心动画模式、时间轴、ScrollTrigger、框架集成、性能指导
- 插件pecific 工作流：ScrollToPlugin、ScrollSmoother、Flip、Draggable、Inertia、Observer、SplitText、ScrambleText、SVG & physics plugins、CustomEase、EasePack、GSDevTools 等
- 工具函数：gsap.utils（clamp、mapRange、normalize、interpolate、random、snap、toArray、selector、wrap、pipe）
- React 集成：useGSAP hook、refs、`gsap.context()`、cleanup、SSR
- 性能最佳实践：transform 优先于 layout props、will-change、batching、ScrollTrigger tips

### 包含内容
- `gsap-plugins`：插件使用指南
- `gsap-utils`：工具函数大全
- `gsap-react`：React 集成
- `gsap-performance`：性能优化
