# Claude Design ｜ Agent 界面设计技能合集

## 仓库
- **jiji262/claude-design-skill**

## 功能描述
面向 Claude Code、Codex 等 Agent 的界面设计技能集合，用于生成更完整、更有设计约束的网页、原型和视觉页面。

### 核心特性
- 强调设计方向而不是直接套模板
- 可用于 landing page、prototype、poster、motion 等场景
- 适合 AI coding 前端设计流程

## 安装
```bash
npx skills add jiji262/claude-design-skill -g
```
