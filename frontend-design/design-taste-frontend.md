# Design Taste Frontend ｜ 前端设计审美优化

## 仓库
- ** Leonxlnx/taste-skill**（安装名为 `design-taste-frontend`）

## 功能描述
给前端 UI 注入强设计品味，告别 AI 模板感（purple gradients、centered heroes、card overuse）。

### 核心特性
- v2 实验版：读取 brief → 推断设计语言 → 调节三个旋钮
  - **VARIANCE**：布局方差
  - **MOTION**：动效强度
  - **DENSITY**：视觉密度
- 严格的反 AI slop 约束
- 内置 GSAP 代码骨架
- 支持 redesign audit protocol
- 框架无关：自动检测项目 CSS 方案（Tailwind / CSS Modules / 等）

### 适合场景
- 创建/改进/审查具有强烈设计品味的前端 UI
- React / Next.js / Tailwind 项目
- 需要 senior-level 设计判断时

## 安装
```bash
npx skills add --skill "design-taste-frontend"
```
