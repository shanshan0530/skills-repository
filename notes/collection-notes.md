# 收录备忘

## 来源查验（必做）
- 新增条目前，先确认仓库 / 官网链接能打开、内容能对上截图或描述。
- 只收“我看了、觉得能用”的东西；截图里没有链接、网上也搜不到的，先别收。

## 归类方式
- 有明确开源仓库 / 官网的 → 按分类放 Markdown 条目。
- 只是设计灵感 / 交互细节 / 无法定位原作的 → 放 `notes/` 备忘，不进正式列表。

## 条目格式
- 文件名：小写 + 连字符，`xxx.md`。
- 必须有：来源（仓库/官网链接）、功能描述、分类标签。
- 来源模糊的条目不写“来源”，只写“参考自社区分享”或直接不放。

## 不收录的情况
- 无法验证原始链接或仓库的。
- 只有截图、没有可访问地址的。
- 信息未核实就写死的。
