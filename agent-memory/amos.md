## 功能描述

把 agent 记忆当操作系统服务来做：typed atoms + 证据链 + 来源可追溯 + 记忆升降级与自治维护，核心主张是长期记忆不该只存成英文摘要，而应存在规范化记忆基座上、按需生成视图。
