# Rescue Tokens ｜ 紧急 Token 优化

## 仓库
- ** valorisa/Claude-Skills** → `rescue-tokens`

## 功能描述
当检测到 rate limit、高上下文或 5+ MCP 加载时自动激活，通过 9 种优化模式防止 token 耗尽。

### 核心特性
- 自动检测：上下文 ≥40%、rate limit、5+ MCPs
- 9 种优化模式
- 宣称 90% token 减少（紧急场景）
- 修复：无限对话、冗余输出、错误模型选择、MCP 膨胀、昂贵文件
