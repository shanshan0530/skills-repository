# Bough ｜ AI 工作日志可视化工具

## 仓库
- ** nickelsec/bough**

## 功能描述
Claude Code 和 Codex 的工作日志可视化工具——把 AI 的每一天、每一个 prompt、每一次 commit 都画出来。

### 核心特性
- 一个 Go 二进制文件，本地运行
- 不发送任何数据到远端
- 可视化：一天、工作内容、每个 prompt、commit 记录
- 支持 Claude Code 和 Codex

### 使用场景
- 回顾 AI 辅助编程的工作历程
- 分析 prompt 使用频率
- 可视化 commit 与 prompt 的关联
