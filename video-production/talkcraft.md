# Talkcraft ｜ 口播解说视频制作

## 仓库
- ** Vincentwei1021/video-talkcraft**

## 功能描述
把 Claude Code / Codex 变成口播解说视频的动态设计工作室：输入口播稿 + 成品配音，自动生成带动效的解说视频。字级时间戳对齐、反幻灯片相机系统、Remotion 渲染。

### 核心特性
- 字级 voiceover 同步（本地 median 20–40ms/字符）
- 78 张动效配方卡
- 7 层反幻灯片镜头系统（连续相机曲线、视差平面、呼吸环境）
- 纯剪字幕（plain-cut subtitles）
- 三重验收关卡（triple-gate QA）
- 支持中文口播优先，中英混排

### 适合场景
- 知识科普视频
- 产品评测
- 新闻解读
- 观点锐评
- 横屏口播/解说类视频

### 输入要求
- 口播稿（文本）
- 成品配音（任意 TTS 或真人录音）
- 人物出镜素材与 B-roll 可选
