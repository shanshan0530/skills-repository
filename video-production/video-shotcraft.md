# Video Shotcraft ｜ 电影级产品视频制作

## 仓库
- ** Vincentwei1021/video-shotcraft**

## 功能描述
把 Claude Code 或 Codex 变成动态设计工作室：输入产品，自动完成分镜、动画、音效设计，生成电影级宣传/营销/发布/演示视频。基于 Remotion 实现真实页面截图、2.5D 镜头运动、节拍同步剪辑、电影级 SFX。

### 核心特性
- 157 张镜头配方卡（10 个功能类别）
- 214 种运动风格 + 214 个动态预览
- 真实页面截图（非占位符）
- 2.5D 镜头运动 + 节拍同步剪辑
- 电影级音效设计（SFX）
- 生产级 Remotion 模板
- 支持多语言（中文 / 英文 / 日文）

### 适合场景
- 产品演示视频
- 营销宣传片
- 功能发布视频
- Demo 视频制作
