## 功能描述
基于 Wan 3.0 Prime API 的多模态参考素材生成视频 skill。

### 核心特性
- 多模态输入：图片 + 视频 + 音频 + 文本
- 单次请求支持：最多 10 张图片、5 个视频、5 个音频片段
- 支持文生视频（text-to-video）、图生视频（image-to-video）、参考视频（reference-to-video）
- 2-30 秒可调时长（整秒）
- 同步音效和对话

### 输入限制
- 图片：≤10，jpeg/png/webp/bmp/tiff/gif，30MB/张
- 视频：≤5，mp4/mov，50MB/个
- 音频：≤5，mp3/wav，15MB/个
- 文本：自然语言 prompt
- 总文件数：≤12（图片+视频+音频）
- 每次请求至少需要一个参考输入 + prompt
