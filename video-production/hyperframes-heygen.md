# HyperFrames ｜ 开源视频生成引擎

## 仓库 / 官网

- [GitHub: hyperframes-com/hyperframes](https://github.com/hyperframes-com/hyperframes)（HeyGen 开源替代）

## 功能描述

开源的 HeyGen 替代方案，基于 Web 技术的 AI 视频生成引擎，支持数字人、口播视频、多语言配音。

## 核心特性

- 数字人视频生成与口型同步
- 支持多语言配音与字幕生成
- 基于 Web 标准，可嵌入现有工作流
- 开源可自托管

## 适合场景

- 批量生成产品介绍/教程视频
- 多语言本地化内容生产
- 需要数据隐私的企业级视频生成
