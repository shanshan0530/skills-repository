# Video Edit ｜ 视频编辑（排行榜 #6）

## 来源
- Codex Weekly Index / forcodedex.com（本周排行 #6，16,489 次安装）

## 功能描述
使用自然语言编辑视频：去除静音、添加字幕、文本叠加、速度调整。

### 核心特性
- 自然语言指令
- 去除静音片段
- 字幕生成（Hormozi / standard / minimal 三种风格）
- 文本叠加
- 速度调整
- 基于 FFmpeg + Whisper

### 支持 Agent
OpenClaw / Claude Code / Codex / Cursor / Windsurf / Cline / Roo Code / Goose / Continue / Kilo / Amp
