# LibreChat ｜ 多模型统一对话界面

## 仓库 / 官网

- [GitHub: Danny-avila/LibreChat](https://github.com/danny-avila/LibreChat)

## 功能描述

一个界面同时接入 ChatGPT、Claude、Gemini 等多个主流大模型，支持多模型切换、对话管理和 Prompt 自定义。

## 核心特性

- 统一界面聚合多个 AI 模型（OpenAI、Anthropic、Google 等）
- 支持多轮对话与历史记录管理
- 可自定义 System Prompt 与模型参数
- 支持多用户与 API Key 管理
- 开源可自部署

## 适合场景

- 需要同时对比多个模型的回答
- 团队共享 AI 账号与 Prompt
- 替代 ChatGPT Plus 多模型切换痛点
