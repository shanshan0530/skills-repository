# Nango ｜ 开源 API 集成平台

## 仓库 / 官网

- [GitHub: NangoHQ/nango](https://github.com/NangoHQ/nango)

## 功能描述

面向开发者的开源 API 集成与连接管理平台，简化第三方 API（如 CRM、HR、支付、通讯）的 OAuth、认证与数据同步。

## 核心特性

- 统一接口管理数百种第三方 API
- 内置 OAuth 2.0 / API Key 认证流程
- 支持数据同步与 webhook 回调
- 可嵌入现有应用或作为独立服务部署

## 适合场景

- 快速接入第三方 SaaS API（Salesforce、HubSpot、GitHub 等）
- 构建集成平台即服务（iPaaS）
- 减少重复认证与 SDK 维护成本
