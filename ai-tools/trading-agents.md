# TradingAgents ｜ AI 多 Agent 量化交易框架

## 仓库 / 官网

- [GitHub: TauriResearch/TradingAgents](https://github.com/TauriResearch/TradingAgents)

## 功能描述

基于 LLM 的多 Agent 协作量化交易框架，模拟研究员、分析师、风控、交易员等角色，实现从信息收集到下单执行的全流程自动化。

## 核心特性

- 多 Agent 协作：研究员、分析师、风控、交易员等角色分工
- 支持回测与模拟交易
- 基于 LLM 进行市场信息解读与决策
- 模块化架构，可扩展策略

## 适合场景

- 量化交易研究
- 自动化交易策略开发
- AI 金融 Agent 原型验证
