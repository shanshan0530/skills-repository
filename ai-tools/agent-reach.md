# Agent Reach ｜ AI Agent 一键联网能力增强工具

## 仓库 / 官网

- [GitHub: panniantong/agent-reach](https://github.com/Panniantong/Agent-Reach)（83k Stars，MIT，Python 3.10+）

## 功能描述

给 AI Agent 一键装上互联网能力，当下最稳的接入方式，替你选好、装好、体检好。

- 把多个平台的搜索和读取工具直接接入 Agent
- 支持网页正文、B站搜索、YouTube字幕、GitHub项目等内容读取
- 在聊天里就能让它帮你查资料、读内容
- 保姆级教程，一键安装

## 核心特性

- 多平台搜索与内容读取（网页、B站、YouTube、GitHub）
- 模块化设计，易于扩展
- 支持本地命令执行（Codex 等）
- 多语言支持：快速开始、English、日本語、한국어
- 设计理念文档完善

## 适合场景

- Agent 需要联网搜索资料时
- 需要读取视频字幕或网页正文时
- 不想手动复制粘贴链接给 AI 时
