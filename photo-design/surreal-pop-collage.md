## 仓库

## 功能描述
把任意照片变成超现实波普拼贴画——照片去色保留为"现实锚"，背景换成巨大平涂色形，全图只有一个"不可能的巨物"。

### 核心特性
- 照片去色保留为"现实锚"
- 背景换成巨大平涂色形
- 全图只有一个"不可能的巨物"
- 超现实波普艺术风格
- 支持 Kimi Code / Claude Code / Codex 等 agent 工具
- 提供 30 秒版快速用法和完整四段式 prompt 配方
