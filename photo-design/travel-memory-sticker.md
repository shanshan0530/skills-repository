# Travel Memory Sticker ｜ 旅行记忆贴纸卡

## 仓库
- ** carolinaaafy/travel-memory-sticker-card**

## 功能描述
将旅行、风景、人物和生活方式照片转换为横向 3:2  collectible memory cards（收藏记忆卡）。

### 核心特性
- 横向 3:2 比例
- Matte gouache 和 cut-paper 美学
- 主导的无框编辑插图
- 3 个场景衍生的英文关键词
- 6 个模切日记贴纸（tactile paper textures + subtle drop shadows）
- 精确的艺术指导和提示词工作流
- 质量检查确保照片简化为怀旧海报风格艺术
