# GC Minimal Zine Poster ｜ 极简 Zine 海报

## 仓库
- ** LiamGvchi/gc-minimal-zine-poster**

## 功能描述
将照片转换成极简、留白充足、带手绘二创元素的 Zine 风格海报。

### 核心特性
- Content → visual metaphor → prompt → generated raster → inspection
- Photo Input：分配图像角色和保护级别
- Reference Analysis：检查真实文件并返回观察证据
- Prompt-only：返回最终四段式提示词和配方
- 非海事主题回归测试

### 照片角色分类
- Edit target：照片或其可识别的主体必须出现在最终海报中
- Reference image：仅使用其风格、颜色、构图、纹理或情绪
- Supporting insert：在照片中插入一个指定的人物、物体、纹理或片段
