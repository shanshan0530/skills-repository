# Mono Color ｜ 单色 / 双色编辑印刷视觉

## 仓库
- **yanliudesign/mono-color-skill**
- Skill 名：`mono-color`

## 功能描述
把主题、句子、文章想法、物体或参考照片，转换成原创的单色或受控双色编辑视觉，适合海报、zine、肖像、包装和视觉笔记。

### 核心特性
- 默认采用受控双色：一块主色印版 + 一块严格分工的强调色印版
- 明确要求单色 / monochrome 时保持纯单色
- 强调纸张留白、网点 / risograph / photocopy 等机械印刷质感
- 使用白、冷灰或浅米色作为基底，不默认做旧
- 强调 serif / grotesk / mono 的强层级排版
- 有明确的原创性约束，不照抄参考图构图、文案、Logo 或版式
- 自带颜色、排版、构图、节奏与印刷瑕疵设计系统

### 适合场景
- 单色海报、双色印刷、monochrome editorial poster
- Risograph / 孔版印刷 / 网点照片
- Zine、文化海报、视觉田野笔记
- 想把照片或主题转成克制的编辑印刷视觉

## 使用
```bash
npx skills add yanliudesign/mono-color-skill
```
