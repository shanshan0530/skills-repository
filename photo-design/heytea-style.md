# Heytea Style ｜ 喜茶风格儿童简笔画海报

## 仓库
- ** Hchen1218/heytea-style**

## 功能描述
把生活照片做成"真实物件 + 儿童简笔画 + 歪扭手写字"的竖版海报。

### 核心特性
- 保留一个真实物件作为摄影锚点
- 粗黑、笨拙、带断笔感的儿童简笔画小人
- 歪扭中文手写标题
- 大面积白底留白（物件占画面 20%-45%）
- 两套模板：带字版 / 无字版
- 中文字体单独处理：先生成无字底图，再用参考板和标题层还原

### 风格核心四层
1. 真实物件锚点
2. 大面积白底留白
3. 粗黑儿童简笔画
4. 歪扭中文手写标题
