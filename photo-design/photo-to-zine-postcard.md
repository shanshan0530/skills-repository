# Photo to Zine Postcard ｜ 照片转 Zine 风格明信片

## 仓库
- ** Whiplashzeb/photo-to-zine-postcard**
- 备选：** shenchangyi/photo-to-monthly-zine-postcard**（带文学/音乐策展）

## 功能描述
把拍摄的照片转换成一套极简、留白充足、带手绘二创元素的 Zine 风格明信片（正反面）。

### 核心特性
- 正面：上方完整嵌入原始照片并保持原图比例；下方保留大量留白，生成手绘主元素 + 极简元数据 + 3 个取自原图的色块
- 背面：统一、可书写的明信片布局（邮票区、分割线、地址线、留言区域）
- 纵向 `2:3`，参考尺寸 `100×150 mm / 4×6 in`
- 暖白 / 象牙白纸张背景
- 手绘二创：水彩 / 水粉 / 墨线 / 拼贴式
- 适合后续 4× 超分辨率放大

### 设计原则
1. 原始照片优先：原图始终是视觉主体
2. 保持原始比例：不拉伸、不随意裁切
3. 大量留白：保持安静、克制的编辑设计感
4. 只选择一个强主元素
5. 优先手绘二创

## 安装
```bash
npx skills add --skill photo-to-zine-postcard
```

请读取 SKILL.md，把我上传的照片生成一套 Photo to Zine Postcard 明信片正反面。
