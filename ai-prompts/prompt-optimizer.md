# Prompt Optimizer ｜ 提示词优化器

## 仓库
- ** Samuel-Shek/prompt-optimizer-skill**
- 备选：** linshenkx/prompt-optimizer**

## 功能描述
把你随手写的一句话、一段粗糙需求、一份混杂的 system prompt，改写成可直接复制给任意 AI 使用的终版提示词。

### 核心特性
- 单用途 Skill：只优化提示词，不执行任务本身
- 支持多平台适配：Claude / GPT / Gemini / DeepSeek / Codex / OpenClaw
- 文生图提示词优化（T2I / I2I）
- 前后效果直观对比（before → after）
- 双模式优化：System Prompt + User Prompt

### 适合场景
- 优化一段已有 prompt
- 把口语化需求变成专业 AI 指令
- 重写 system prompt / agent 指令

## 安装
```bash
# Claude Code
npx skills add --skill prompt-optimizer

# 或直接复制 SKILL.md 到项目
```
