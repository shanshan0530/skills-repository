## 功能描述
OrangeChat Agent Skill，用于在编码、代码审查、错误处理和技术方案评估时，强制执行统一的开发与协作规范。

### 核心特性
- **一次性完整交付**：所有需求一次性解决，禁止分步补丁；代码库中的同类问题同步修复。
- **不做无依据假设**：遇到依赖、边界情况或集成点不明时，立即停止并提问。
- **诚实面对限制**：无法实现的需求直接拒绝；替代方案必须通过严格的三步协议提交，由用户决定。
- **先搜索再动手**：技术细节、API、库版本、参数名等不确定时，先搜索官方文档再写代码。
- **干净交付**：只交付完整文件，不附带总结、回顾或教程。
- **真实错误处理**：禁止空 catch 块和原始 stdout 打印；使用结构化日志，包含错误位置、完整堆栈和关键运行时变量。

### 适合场景
- 代码生成、审查或修改
- 错误、异常和日志处理
- 技术方案评估与选型
- 团队协作规范强制执行

### 关键规则摘要
| 规则 | 说明 |
|---|---|
| 一次性完整交付 | 所有需求单次闭环，禁止部分补丁 |
| 无假设 | 歧义 → 立即提问 |
| 直接拒绝限制 | 无法实现直接说明；替代方案需三步协议 |
| 搜索优先 | 官方文档优先于猜测 |
| 干净交付 | 只交付完整文件，无冗余内容 |
| 真实错误处理 | 结构化日志，禁止空 catch / print |

## 设计原则
1. **One-pass delivery** — 一次通过，完整闭环
2. **No assumptions** — 歧义即提问
3. **Honest limitations** — 直接说明限制，替代方案经用户决策
4. **Search-first** — 官方文档验证
5. **Clean output** — 完整文件，无废话
6. **Structured error handling** — 位置 + 堆栈 + 上下文
