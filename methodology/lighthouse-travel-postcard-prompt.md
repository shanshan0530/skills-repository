# Lighthouse 旅行纪念明信片提示词模板

## 核心理念
将上传的照片制作成一张竖版旅行纪念明信片，保留照片作为唯一内容来源，结合手撕纸边缘、复古旅行插画和邮戳元素。

## 完整提示词
```
将我上传的照片制作成一张竖版旅行纪念明信片。

保留照片作为唯一内容来源。成品上半部分约占画面高度的 50%–58%。
在照片下缘使用自然、不规则的手撕纸边缘，直接过渡到下半部分的暖象牙白/米白色档案纸区域。纸张区域可有极轻微天然纸纤维感。

在下方纸张区域，以照片中的核心景观为依据，绘制一幅具象但精简的复古旅行插画：保留最有辨识度的核心景色，以及主要的空间关系。使用丝网印刷、孔版印刷与干刷笔触结合的质感；边缘略有手工印刷的不规则感，但画面仍需清晰、优雅、可读。插画不应成为小色块或图标，而应是具有景物细节的简化风景画。

色彩仅取自原照片，并压缩为有限色系：一个主色、一个深色结构色、一个浅中性色，搭配一至两个小面积强调色。保持低饱和、克制、具有旅行纪念品般的安静感。

版式：
- 在撕纸边缘下方左侧写：[简短英文标题]
- 在纸张区域右上，加入一枚克制的圆形邮戳，文字为：[地点英文名] 与 [国家/地区英文名]，并配三条简洁的邮戳横线。
- 在底部左侧写：PLACE · [地点英文名]
- 在底部右侧写：DATE · [YYYY.MM]
```

## 设计要点拆解

### 1. 照片占比
- 上半部分：50%–58% 画面高度
- 照片作为唯一内容来源，不重绘、不滤镜、不扩展

### 2. 手撕纸边缘
- 自然、不规则
- 从照片下缘直接过渡到档案纸区域
- 极轻微天然纸纤维感

### 3. 复古旅行插画
- 具象但精简
- 保留核心景色和主要空间关系
- 丝网印刷 / 孔版印刷 / 干刷笔触质感
- 边缘有手工印刷不规则感
- 清晰、优雅、可读

### 4. 色彩系统
- 仅取自原照片
- 压缩为有限色系：
  - 一个主色
  - 一个深色结构色
  - 一个浅中性色
  - 一至两个小面积强调色
- 低饱和、克制、旅行纪念品般的安静感

### 5. 版式布局
- 撕纸边缘下方左侧：简短英文标题
- 纸张区域右上：圆形邮戳（地点英文名 + 国家/地区英文名 + 三条横线）
- 底部左侧：PLACE · [地点英文名]
- 底部右侧：DATE · [YYYY.MM]
