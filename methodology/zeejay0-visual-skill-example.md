# Zeejay0 Visual Skill 使用示例

## 来源
- @豆包 分享的核心提示词
- 使用 @Zeejay0 的 Visual Skill（gathered-scenes-zine-skill）

## 核心提示词
```
隐在林木间的红色东方五重塔，水墨枯树、墨色树丛，做旧米黄宣纸底色，水墨写意国风，撕边晕染复古肌理，左上方有英文小字 Tower after branches，红黑撞色，禅意朦胧。
```

## 功能说明
Zeejay0 的 Visual Skill 功能是：
- 保留图片核心主体
- 弱化原始构图做风格重构

## 使用方式
1. 找到 Zeejay0 的 Visual Skill（gathered-scenes-zine-skill）
2. 使用上述提示词
3. 可上传参考图
