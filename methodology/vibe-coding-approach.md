# Vibe Coding 最佳提问方式

## 核心理念
别只说"帮我做个 App"，采用"先调研，再定方案，最后动手"的三步法。

## 推荐提问模板
```
我要做一个 XXX项目。

先别写代码、去 GitHub 调研同类开源项目，
对比功能、架构、技术选型和不足，
再给我一套落地方案，确认后再开发。
```

## 三步法
1. **先调研**：去 GitHub 调研同类开源项目
2. **再定方案**：对比功能、架构、技术选型和不足，给出落地方案
3. **最后动手**：确认方案后再开发

## 优势
- 借鉴已有经验，少走弯路
- 避免重复造轮子
- 提前发现潜在问题和风险
- 确保技术选型合理
