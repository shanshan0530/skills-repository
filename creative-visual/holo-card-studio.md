# Holo Card Studio ｜ 全息镭射卡 / 光栅翻转卡

## 仓库
- ** EverettFish/holo-card-studio**
- 别名：layered-holo-card-skill

## 功能描述
用 AI 生成的画作 + Blender + Three.js，创建交互式 3D 全息收藏卡网站。

### 核心特性
- 双生产线：
  1. **Holographic Route**：多层镭射卡（单图）
  2. **Lenticular Route**：双图光栅卡 / 翻转卡 / 双形态卡
- AI 生成全彩浮世绘或水墨动漫勾线风格 artwork
- 输出：可编辑 `.blend`、四层资产图、交互式网页（GLB + Three.js）
- 多卡展厅：自动按人物/风格/主题/稀有度分类

### 输出交付物
- `card.blend`：在 Blender 里继续调材质、灯光
- `assets/` 四层图
- `card-config.json`：配置名字、编号、稀有度
- 响应式网页：鼠标/触控倾斜驱动视角切换
